プライバシーポリシー

この翻訳は理解を助けるために提供されています。相違がある場合は英語版が優先されます。

発効日: 2026年8月11日

1. はじめに

当社は、Music Memory モバイル アプリケーション (以下「サービス」) を運営しています。このプライバシー ポリシーでは、お客様が当社のサービスを使用する際に、当社がお客様の個人情報をどのように収集、使用、開示、保護するかについて説明します。サービスにアクセスまたは使用すると、このプライバシー ポリシーに記載されているデータの取り扱いに同意したものとみなされます。このプライバシー ポリシーの条項に同意しない場合は、サービスにアクセスしたり、サービスを使用したりしないでください。

2. 当社が収集する情報

2.1 お客様が直接提供する情報

  • アカウント情報: 電子メール アドレス、ユーザー名、およびパスワード (電子メール登録用)。または、Apple サインインまたは Google サインインによって提供される認証トークン。
  • プロフィール情報: ユーザー名、プロフィール写真 (アバター)、およびカードの色の設定。
  • 仕訳帳: 曲名、アーティスト名、日記のテキスト（最大500ワード）、初めて聞いた日付、およびオプションの位置データ（地名、緯度、経度）。
  • メディアのアップロード: 日記エントリに添付する写真とビデオ (画像は最大 10 MB、ビデオは最大 50 MB、エントリごとに最大 5 ファイル)。
  • コメント: コミュニティ エントリに投稿するテキスト コンテンツ (最大 500 文字)。
  • 機能のリクエスト: あなたが送信した機能提案のタイトルと説明。
  • オンボーディングアンケートの回答: 音楽鑑賞の習慣や日記の趣味に関するオプションの質問に答えます。
  • サポートコミュニケーション: サポートのために当社に連絡する際に提供する情報。

2.2 自動的に収集される情報

  • オプションの分析データ: お客様が明示的に同意した場合、当社は PostHog を使用して、最小化された画面ルート、機能のインタラクション、オンボードの列挙型の選択、およびアプリのライフサイクル イベントを収集します。 PostHog は、Supabase アカウント ID や電子メール アドレスではなく、ランダムな分析識別子を受け取ります。
  • デバイス情報: デバイス モデル、オペレーティング システムのバージョン、およびアプリケーションのバージョン (診断とサポートの目的で収集されます)。
  • 購読ステータス: RevenueCat を通じて処理される、サブスクリプション層と資格に関する情報。

2.3 当社が収集しない情報

  • 正確な GPS 位置情報: 当社はデバイスの GPS にアクセスしたり、位置データを自動的に収集したりしません。位置情報は、アプリ内の位置ピッカーを使用して手動で場所を検索して選択した場合にのみ保存されます。
  • 連絡先またはアドレス帳: 私たちはあなたのデバイスの連絡先にはアクセスしません。
  • マイクまたはカメラ (受動的): カメラと写真ライブラリへのアクセスは、メディアのアップロードを積極的に選択した場合にのみ使用されます。

3. お客様の情報の使用方法

当社は収集した情報を次の目的で使用します。

  • サービスの提供、維持、改善のため
  • 身元を認証し、アカウントを管理するため
  • サブスクリプションを処理および管理するには
  • 公開エントリを他のコミュニティ メンバーに表示するには
  • コンテンツとのインタラクション (いいね!、コメント、返信) に関する通知を配信するため
  • 利用規約とコミュニティガイドラインを強制するため
  • 詐欺、悪用、セキュリティ問題を検出、防止、対処するため
  • 使用パターンを分析し、ユーザーエクスペリエンスを向上させるため
  • お客様のサポートリクエストや連絡に対応するため
  • 連続記録やアカウントアクティビティに関連するプッシュ通知を（お客様の同意を得て）送信するため

3.1 コミュニティの安全とメディアのモデレーション

公開テキストは、サーバーが所有する決定論的な安全性とスパム対策ルールを使用してチェックされます。合格したコンテンツはすぐに公開されます。ユーザーの報告と異議申し立てにより、承認された人間のモデレータに対するケースが作成され、モデレーターは報告された共有テキストと添付メディアを確認して、それを保持するか削除するかを決定できます。モデレータには、プライベートな「自分だけ」エントリを参照する権限はありません。ユーザーは、報告されたコンテンツをすぐに非表示にしたり、アカウントをブロックしたり、モデレーションの決定に異議を申し立てたりすることができます。

写真とビデオは、Cloudflare Worker によって検証され、再エンコードされます。これらは、Amazon Rekognition、Google Gemini、または別の外部の画像認識プロバイダーや AI モデレーション プロバイダーには送信されません。承認されたモデレータは、関連するコンテンツが報告または異議申し立てされた場合にのみ、共有メディアを閲覧できます。

4. データの保管とセキュリティ

4.1 ストレージインフラストラクチャ

  • スーパーベース (PostgreSQL): アカウント情報、仕訳、プロフィール、反応、コメント、通知を含むすべての構造化データ。
  • クラウドフレア R2: 暗号化されたオブジェクトとして保存されるメディア ファイル (画像、ビデオ、アバター、コレクション カバー)。
  • クラウドフレア KV: Apple Music API トークンと要求された AI 翻訳の一時キャッシュ。翻訳キャッシュ レコードは 90 日以内に期限切れになります。
  • オンデバイスストレージ: 認証トークンは、expo-secure-store (iOS キーチェーン / Android キーストア) を使用して安全に保存されます。ローカル設定は MMKV を使用して保存されます。

4.2 セキュリティ対策

当社は、お客様のデータを保護するために次のような業界標準のセキュリティ対策を実装しています。 ユーザーが自分のデータのみにアクセスできるようにする行レベル セキュリティ (RLS) ポリシー。 JWKS 検証による JWT ベースの認証。デバイス上の安全なトークンストレージ。転送中のすべてのデータに対する HTTPS 暗号化。およびオプションの 2 要素認証 (TOTP)。ただし、電子的な送信や保存の方法は完全に安全ではなく、絶対的なセキュリティを保証することはできません。

5. サードパーティサービス

当社は、サービスを運営する目的のみで、次のサードパーティ サービス プロバイダーと情報を共有します。

  • スーパーベース: 認証、データベースホスティング、リアルタイムデータ同期。 プライバシーポリシー
  • クラウドフレア: バックエンド インフラストラクチャ (ワーカー)、メディア ストレージ (R2)、およびコンテンツ配信。 プライバシーポリシー
  • ポストホッグ: 明示的な同意後のオプションの製品分析。電子メール アドレス、アカウント ID、日記やコメントのテキスト、ユーザー名、正確な曲名、検索、正確な場所、メディア URL は送信されません。 プライバシーポリシー
  • 収益項目: サブスクリプションの管理と支払い処理。ユーザー ID は資格を管理するために共有されます。 プライバシーポリシー
  • Apple (Apple Music API、Apple サインイン): ソングカタログデータの取得と認証。 プライバシーポリシー
  • Google (Google サインインおよび Gemini): 認証サービス。明示的な翻訳リクエストと同意があった場合にのみ、Google Gemini を介した言語検出と翻訳が行われます。 プライバシーポリシー そして Gemini API 規約
  • OpenStreetMap/指名: 場所の検索クエリ。検索テキストのみが送信されます。個人識別情報は送信されません。 プライバシーポリシー
  • Expo (プッシュ通知): デバイスへのプッシュ通知の配信。 プライバシーポリシー

当社は、マーケティング目的でお客様の個人情報を第三者に販売、貸与、または取引することはありません。

6. オプションの製品分析

PostHog 分析は、「分析を許可する」を個別に選択しない限りオフのままです。同意を拒否したり、後で同意を撤回したりしても、サブスクリプションやその他の機能は制限されません。有効にすると、ミュージック メモリーはランダム分析識別子と大まかなイベント事実を使用して、機能の使用状況と信頼性を把握します。当社はこの情報を企業間の追跡やターゲットを絞った広告に使用することはありません。

[設定] → [オプションの分析を共有] で同意を撤回できます。キャプチャはすぐに停止し、ローカルの PostHog 状態はクリアされ、オプトインしない限り PostHog は再度初期化されません。PostHog は、サービス保持設定に従って、以前に収集され、同意されたイベント データを保持します。 Music Memory は、アカウントの永久削除の一環として、削除のためにランダムな分析識別子を送信します。

7. オプションの AI 翻訳

AI 翻訳はオプションであり、18 歳以上のユーザーのみが利用できます。初めて翻訳をリクエストするとき、ミュージック メモリーは翻訳の適格性を判断するためにのみあなたの生年月日を尋ねます。認証された Cloudflare Worker がその計算を実行し、正確な日付をすぐに破棄します。当社は、肯定的な適格性の結果、タイムスタンプ、およびポリシーのバージョンのみを保持します。生年月日は保存されず、Google Gemini に送信されることもありません。

翻訳は、テキストを選択し、翻訳をリクエストし、年齢チェックに合格し、現在のバージョンに対する別途の同意を提供した後にのみ実行されます。 Music Memory は、選択された日記またはコメント テキストのみを Cloudflare Worker 経由で Google Gemini に送信します。 Google はサードパーティの AI プロセッサとして機能し、ソース言語を検出して翻訳を返します。 Gemini リクエストには、ユーザー ID、電子メール、ユーザー名、場所、メディア、エントリー ID、または生年月日は含まれません。

翻訳の同意は翻訳にのみ適用されます。セクション 3.1 で説明されている決定論的な安全性スクリーニングとレポート主導の人によるレビューは、Google Gemini または別のサードパーティ AI モデレーション プロバイダーにテキストを送信しません。

Music Memory は、元のテキストのハッシュ、翻訳された出力、および検出された言語を Cloudflare KV に最大 90 日間キャッシュする場合があります。生の翻訳テキストは、製品分析や一般的なワーカー ログには含まれません。 Google は、Google の該当するプライバシー規約、Gemini API 規約、およびデータ処理規約に従って、選択されたテキストを Google またはそのサブプロセッサーが事業を展開している国で処理することがあります。このポリシーではなく、これらの規約が Google によるリクエスト データの保持と使用を規定します。デプロイされたサービス契約で明示的に保護が提供されていない限り、Google がモデルのトレーニングからプロンプトを除外することは約束しません。

翻訳以外の機能を失うことなく辞退することができます。また、[設定] → [AI 翻訳の同意] でいつでも同意を取り消すことができます。今後のリクエストは停止され、ローカルの同意記録はクリアされます。所有するコンテンツにインデックス付けされた翻訳キャッシュ レコードは、アカウントの永久削除中に削除され、すべてのキャッシュ レコードは 90 日以内に自動的に期限切れになります。

8. データの共有と可視性

  • プライベートエントリー: デフォルトでは、すべての日記エントリは非公開であり、自分だけが閲覧できます。
  • 一般エントリー: エントリを公開することを選択した場合 (Pro サブスクリプションが必要)、あなたのユーザー名、アバター、日記のテキスト、最初に聞いた日付、場所の名前、および添付されたメディアが、同じ曲のエントリを持つ他のユーザーに表示されるようになります。
  • プロフィール情報: コミュニティ機能 (公開エントリ、コメント、反応) を操作するときに、あなたのユーザー名とアバターが他のユーザーに表示されます。
  • 反応とコメント: 公開エントリに対するあなたの反応 (好き/嫌い) とコメントは、他のユーザーに表示されます。

9. データの保持

当社は、お客様のアカウントが有効である限り、またはサービスを提供するために必要な限り、お客様の個人情報を保管します。具体的には:

  • アクティブなアカウント: アカウントがアクティブな間、データは無期限に保持されます。
  • 削除されたアカウント: アカウント削除をリクエストすると、データは 14 日間の猶予期間に入ります。この期間が経過すると、日記エントリ、メディア ファイル (Cloudflare R2 から)、反応、レポート、コメント、アンケート回答、プロフィール データ、認証資格情報を含むすべてのデータが永久的かつ不可逆的にパージされます。
  • 分析データ: 同意された PostHog イベント データは、PostHog のサービス保持設定に従って保持されます。 Music Memory は、アカウントが完全に削除されると、削除のためにランダムな分析識別子を送信します。

10. お客様の権利と選択

あなたの管轄区域に応じて、あなたは自分の個人データに関して次の権利を有する場合があります。

  • アクセス: お客様は、当社がお客様に関して保持している個人データのコピーを要求することができます。
  • エクスポート: [設定] 画面から、いつでもすべての日記エントリをマークダウン形式でエクスポートできます。
  • 訂正： アプリケーションを通じてプロフィール情報 (ユーザー名、アバター) を更新できます。
  • 削除: [設定] 画面からアカウントの完全な削除をリクエストできます。これにより、14 日間の猶予期間が開始され、その後永久にデータが削除されます。
  • 同意の撤回: いつでもデバイスの設定を通じてプッシュ通知の許可を取り消したり、ミュージック メモリー設定でオプションの分析や AI 翻訳の同意を取り消したりすることができます。
  • 可視性の制御: 公開エントリはいつでも非公開に戻すことができます。

これらの権利を行使するには、下記までご連絡ください。 support@musicmemory.app.

11. 子供のプライバシー

本サービスは 13 歳未満の子供を対象としていません。当社は、13 歳未満の子供から故意に個人情報を収集することはありません。保護者の同意なしに 13 歳未満の子供から個人データを収集したことが判明した場合、当社はその情報を速やかに削除する措置を講じます。当社が 13 歳未満の児童から情報を誤って収集したと思われる場合は、直ちに当社にご連絡ください。

12. 国際的なデータ転送

お客様の情報は、お客様の居住国以外の国に転送され、そこで処理される場合があります。当社のサービス プロバイダー (Supabase、Cloudflare、PostHog、RevenueCat、および AI 翻訳をリクエストする場合は Google) はグローバルに運営されています。これらの管轄区域では、お客様の管轄区域とは異なるデータ保護法が適用されている場合があります。

13. このプライバシーポリシーの変更

当社は、このプライバシー ポリシーを随時更新することがあります。当社は、本ポリシーの上部にある「発効日」を更新することにより、また可能な場合にはアプリ内通知を提供することにより、重大な変更をお客様に通知します。変更後もサービスを継続して使用することにより、改訂されたプライバシー ポリシーに同意したものとみなされます。このプライバシー ポリシーを定期的に確認することをお勧めします。

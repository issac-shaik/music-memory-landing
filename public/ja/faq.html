人々が尋ねるすべてのこと Music Memory — 音楽ジャーナルと歌日記アプリ — 曲の日記を書き始める前に。

音楽記憶とは何ですか?+

ミュージックメモリーは、 音楽日記と歌日記アプリ あなたの人生の曲を追跡します。曲を記録し、それぞれの曲を最初に聴いた日付と場所をタグ付けし、感じたことを書き留めて写真を添付し​​、時間をかけて音楽の思い出のプライベート アーカイブを構築します。日記のように思えますが、エントリは歌です。

Music Memory は音楽日記アプリですか?+

はい。 Music Memory は音楽ジャーナル アプリです。 歌日記, 音楽日記、または 音楽メモリートラッカー。これは、自分の人生を彩った曲を思い出したい人向けに設計されています。すべてのエントリーが、1 つの曲を瞬間、場所、感情と結びつけています。

ミュージック メモリーはプレイリストとどう違うのですか?+

プレイリストとは曲のリストです。ミュージックメモリーは、 曲にまつわる思い出の日記帳。各エントリには、そのトラックを最初に聞いた時期と場所、何をしていたか、そしてそれを聞いてどのように感じたかが含まれているため、あなたの視聴履歴はキューではなくストーリーのように表示されます。

何年も聴いてきた曲を追跡できますか?+

はい。できます 思い出を埋め戻す 何年も前に聞いた曲については、日付を特定し (1 年や季節だけでも)、場所を追加し、短い思い出を書き留めます。このアプリは、曲を月と章の時系列タイムラインに整理します。

Music Memory は Apple Music や Spotify で動作しますか?+

Music Memory は、 Apple Music カタログ そのため、実際のカバーアートとメタデータがエントリに添付され、アプリからトラックを再生できます。また、 Music Memory コレクションを Apple Music にエクスポートして戻す 実際のプレイリストとして。 Spotify は将来的にサポートされる予定です。

ミュージックメモリーは無料ですか?+

いいえ — Music Memory はサブスクリプションです。あなたは、 3日間の無料トライアル、その場合、プロは $9.99/月または $49.99/年。 Pro には、無制限の思い出、写真とビデオ、位置タグ付け、公開ソング メモリ フィードへのアクセスが含まれます。

Music Memory は iPhone と Android で利用できますか?+

ミュージックメモリーは もうすぐ iOS App Store と Google Play ストアにアクセスします。待機リストに登録すると、発売日に通知が届きます。

私の音楽日記は非公開ですか?+

あらゆる思い出は デフォルトではプライベート。個々のメモリを曲の公開フィードに共有することを選択できますが、メモリごとにオプトインしない限り、何も公開されません。

什么是音乐记忆？+

音乐记忆是 音乐日记和歌曲日记应用程序 用于追踪您生活中的歌曲。您记录歌曲，标记您第一次听到每首歌曲的日期和地点，写下您的感受，并附上照片——随着时间的推移，为您的音乐记忆建立一个私人档案。把它想象成一本日记，但条目是歌曲。

Music Memory 是音乐日记应用程序吗？+

是的。 Music Memory 是一款音乐日记应用程序 — 也称为 歌曲日记, 音乐日记, 或 音乐记忆追踪器。它是为那些想要记住那些为他们的生活打分的歌曲的人而设计的：每一个条目都将一首歌曲与一个时刻、一个地方和一种感觉联系起来。

音乐记忆与播放列表有何不同？+

播放列表是歌曲列表。音乐记忆是 附有歌曲的记忆日记。每个条目都包含您第一次听到这首歌的时间和地点、您当时在做什么以及它给您带来的感受 - 因此您的收听历史记录读起来就像一个故事而不是一个队列。

我可以追踪我多年来听过的歌曲吗？+

是的。你可以 回填记忆 对于您几年前听过的歌曲 - 钉上日期（甚至只是一年或一个季节），添加一个地点，并写下一段短暂的记忆。该应用程序将您的歌曲按照月份和章节的时间顺序组织起来。

Music Memory 可以与 Apple Music 和 Spotify 配合使用吗？+

音乐记忆直接从 苹果音乐目录 因此，真正的封面艺术和元数据会附加到您的条目中，您可以从应用程序中播放曲目。您还可以 将 Music Memory 收藏导出回 Apple Music 作为真正的播放列表。 Spotify 支持将在未来推出。

音乐记忆是免费的吗？+

否——音乐记忆是订阅。你得到一个 3 天免费试用，那么 Pro 是 9.99 美元/月或 49.99 美元/年。 Pro 包括无限的记忆、照片和视频、位置标记以及对公共歌曲记忆源的访问。

我的音乐日记是私人的吗？+

每一段记忆都是 默认为私有。您可以选择将个人记忆分享到歌曲的公共源中，但除非您选择每个记忆，否则任何内容都不会公开。

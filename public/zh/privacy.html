隐私政策

本翻译仅为便于理解而提供。如有任何差异，以英文版本为准。

生效日期： 2026年8月11日

一、简介

我们运营 Music Memory 移动应用程序（“服务”）。本隐私政策解释了当您使用我们的服务时我们如何收集、使用、披露和保护您的个人信息。通过访问或使用服务，您同意本隐私政策中描述的数据实践。如果您不同意本隐私政策的条款，请不要访问或使用本服务。

2. 我们收集的信息

2.1 您直接提供的信息

  • 账户信息： 电子邮件地址、用户名和密码（用于电子邮件注册）；或 Apple Sign-In 或 Google Sign-In 提供的身份验证令牌。
  • 简介信息： 用户名、个人资料图片（头像）和卡片颜色偏好。
  • 日记条目： 歌曲名称、艺术家姓名、日志文本（最多 500 个字）、首次听到日期和可选位置数据（地名、纬度、经度）。
  • 媒体上传： 您附加到日记条目的照片和视频（图像最多 10MB，视频最多 50MB，每个条目最多 5 个文件）。
  • 评论： 您在社区条目上发布的文本内容（最多 500 个字符）。
  • 功能要求： 您提交的功能建议的标题和描述。
  • 入职调查回复： 回答有关您的音乐聆听习惯和日记兴趣的可选问题。
  • 支持通讯： 您在联系我们寻求支持时提供的任何信息。

2.2 自动收集的信息

  • 可选的分析数据： 如果您明确同意，我们将使用 PostHog 收集最小化的屏幕路线、功能交互、入门枚举选择和应用程序生命周期事件。 PostHog 收到随机分析标识符，而不是您的 Supabase 帐户 ID 或电子邮件地址。
  • 设备信息： 设备型号、操作系统版本和应用程序版本（收集用于诊断和支持目的）。
  • 订阅状态： 有关您的订阅级别和权利的信息，通过 RevenueCat 处理。

2.3 我们不收集的信息

  • 精确的 GPS 位置： 我们不会自动访问您设备的 GPS 或收集位置数据。仅当您使用应用内位置选择器手动搜索并选择地点时，才会存储位置信息。
  • 联系人或地址簿： 我们不会访问您的设备联系人。
  • 麦克风或摄像头（被动）： 仅当您主动选择上传媒体时，才会使用相机和照片库访问权限。

3.我们如何使用您的信息

我们将收集的信息用于以下目的：

  • 提供、维护和改进服务
  • 验证您的身份并管理您的帐户
  • 处理和管理您的订阅
  • 向其他社区成员显示您的公开条目
  • 发送有关与您的内容交互的通知（点赞、评论、回复）
  • 执行我们的服务条款和社区准则
  • 检测、预防和解决欺诈、滥用和安全问题
  • 分析使用模式并改善用户体验
  • 回应您的支持请求和通信
  • 发送与条纹和帐户活动相关的推送通知（经您同意）

3.1 社区安全与媒体审核

面向公众的文本会通过服务器管理的确定性安全和反垃圾信息规则进行检查。通过检查的内容会立即发布。用户举报和申诉会创建案件，由获得授权的人工审核人员查看被举报的共享文本和所附媒体，并决定保留或移除。审核人员无法浏览私密的“仅自己可见”条目。用户可以立即隐藏已举报的内容、屏蔽账户，并对审核决定提出申诉。

照片和视频会由我们的 Cloudflare Worker 验证并重新编码。它们不会发送给 Amazon Rekognition、Google Gemini 或其他外部图像识别或 AI 内容审核提供商。只有当相关内容被举报或申诉时，获得授权的审核人员才可以查看已分享的媒体。

4. 数据存储和安全

4.1 存储基础设施

  • Supabase（PostgreSQL）： 所有结构化数据，包括帐户信息、日记条目、个人资料、反应、评论和通知。
  • Cloudflare R2： 作为加密对象存储的媒体文件（图像、视频、头像和收藏封面）。
  • Cloudflare KV： 临时缓存 Apple Music API 令牌和请求的 AI 翻译。翻译缓存记录在不超过 90 天后过期。
  • 设备上存储： 身份验证令牌使用 expo-secure-store（iOS Keychain / Android Keystore）安全存储。本地首选项使用 MMKV 存储。

4.2 安全措施

我们实施行业标准的安全措施来保护您的数据，包括： 行级安全 (RLS) 策略，确保用户只能访问自己的数据；基于 JWT 的身份验证和 JWKS 验证；设备上的安全令牌存储；对传输中的所有数据进行 HTTPS 加密；以及可选的双因素身份验证 (TOTP)。然而，没有一种电子传输或存储方法是完全安全的，我们不能保证绝对安全。

5. 第三方服务

我们与以下第三方服务提供商共享信息，仅用于运营服务的目的：

  • 苏帕巴斯： 身份验证、数据库托管和实时数据同步。 隐私政策
  • 云耀： 后端基础设施（Workers）、媒体存储（R2）和内容交付。 隐私政策
  • 邮政猪： 明确同意后可选的产品分析。我们不会发送电子邮件地址、帐户 ID、日记或评论文本、用户名、确切的歌曲名称、搜索、精确位置或媒体 URL。 隐私政策
  • 收入猫： 订阅管理和付款处理。您的用户 ID 会被共享以管理权利。 隐私政策
  • Apple（Apple Music API、Apple 登录）： 歌曲目录数据检索和验证。 隐私政策
  • Google（Google 登录和 Gemini）： 身份验证服务，并且只有在您明确翻译请求并同意后，才会通过 Google Gemini 进行语言检测和翻译。 隐私政策 和 Gemini API 条款
  • OpenStreetMap/提名： 位置搜索查询。仅传输您的搜索文本；不会发送任何个人标识符。 隐私政策
  • 博览会（推送通知）： 将推送通知传送到您的设备。 隐私政策

我们不会出于营销目的向第三方出售、出租或交易您的个人信息。

6. 可选的产品分析

除非您单独选择“允许分析”，否则 PostHog 分析将保持关闭状态。拒绝或稍后撤回同意不会限制订阅或任何其他功能。启用后，音乐记忆使用随机分析标识符和粗略事件事实来了解功能使用情况和可靠性。我们不会将此信息用于跨公司跟踪或有针对性的广告。

您可以在“设置”→“共享可选分析”下撤回同意。捕获立即停止，本地 PostHog 状态被清除，除非您选择加入，否则 PostHog 不会再次初始化。PostHog 根据其服务保留设置保留先前收集的、同意的事件数据。 Music Memory 提交随机分析标识符以作为永久帐户删除的一部分进行删除。

7. 可选配人工智能翻译

AI 翻译是可选的，并且仅适用于年满 18 岁的用户。当您第一次请求翻译时，音乐记忆会询问您的出生日期，只是为了确定翻译资格。我们经过身份验证的 Cloudflare Worker 执行该计算并立即丢弃确切的日期。我们仅保留积极的资格结果、时间戳和保单版本；出生日期不会被存储，也不会发送到 Google Gemini。

仅在您选择文本、请求翻译、通过年龄检查并提供单独的当前版本同意后，翻译才会运行。 Music Memory 仅通过我们的 Cloudflare Worker 将选定的日志或评论文本发送到 Google Gemini。谷歌充当第三方人工智能处理器来检测源语言并返回翻译。我们不会在 Gemini 请求中包含您的用户 ID、电子邮件、用户名、位置、媒体、条目 ID 或出生日期。

翻译同意仅适用于翻译。第 3.1 节中描述的确定性安全筛查和报告驱动的人工审核不会向 Google Gemini 或其他第三方 AI 审核提供商发送文本。

Music Memory 可以在 Cloudflare KV 中缓存原始文本哈希、翻译输出和检测到的语言长达 90 天。原始翻译文本不包含在产品分析或一般工作人员日志中。 Google 可能会在其或其分处理商运营所在的国家/地区处理所选文本，但须遵守 Google 的适用隐私条款、Gemini API 条款和数据处理条款。这些条款（而非本政策）管辖 Google 对请求数据的保留和使用；我们不承诺 Google 从模型训练中排除提示，除非部署的服务合同明确提供了这种保护。

您可以拒绝，而不会失去任何非翻译功能。您也可以随时在“设置”→“人工智能翻译同意”下撤回同意；未来的请求将停止，并且本地同意记录将被清除。索引到您拥有的内容的翻译缓存记录将在永久帐户删除过程中被删除，并且所有缓存记录将在 90 天内自动过期。

8. 数据共享和可见性

  • 私人条目： 默认情况下，所有日记条目都是私有的，只有您可见。
  • 公开条目： 如果您选择公开条目（需要订阅专业版），您的用户名、头像、日志文本、首次收听日期、地点名称和附加媒体将对其他拥有同一歌曲条目的用户可见。
  • 简介信息： 当您与社区功能（公共条目、评论、反应）互动时，其他用户可以看到您的用户名和头像。
  • 反应和评论： 其他用户可以看到您对公共条目的反应（喜欢/不喜欢）和评论。

9. 数据保留

只要您的帐户处于活动状态或根据提供服务的需要，我们就会保留您的个人信息。具体来说：

  • 活跃账户： 当您的帐户保持活动状态时，数据将无限期保留。
  • 已删除的帐户： 请求删除帐户后，您的数据将进入十四 (14) 天的宽限期。在此期限之后，所有数据都将被永久且不可逆转地清除，包括：日记条目、媒体文件（来自 Cloudflare R2）、反应、报告、评论、调查答案、个人资料数据和身份验证凭据。
  • 分析数据： 同意的 PostHog 事件数据将根据 PostHog 的服务保留设置进行保留。当帐户被永久删除时，Music Memory 会提交随机分析标识符以进行删除。

10. 您的权利和选择

根据您所在的司法管辖区，您可能对您的个人数据拥有以下权利：

  • 访问： 您可以索取我们持有的有关您的个人数据的副本。
  • 出口： 您可以随时通过“设置”屏幕以 Markdown 格式导出所有日记条目。
  • 更正： 您可以通过应用程序更新您的个人资料信息（用户名、头像）。
  • 删除： 您可以通过“设置”屏幕请求完全删除帐户，这将启动 14 天的宽限期，然后永久清除数据。
  • 撤回同意： 您可以随时通过设备设置撤销推送通知权限，并随时在“音乐记忆”设置中撤销可选分析或人工智能翻译同意。
  • 可见性控制： 您可以随时将任何公共条目切换回私人条目。

要行使任何这些权利，请通过以下方式联系我们： 支持@musicmemory.app.

11. 儿童隐私

该服务不针对十三 (13) 岁以下的儿童。我们不会故意收集 13 岁以下儿童的个人信息。如果我们发现我们在未经父母同意的情况下收集了 13 岁以下儿童的个人数据，我们将采取措施立即删除该信息。如果您认为我们无意中收集了 13 岁以下儿童的信息，请立即与我们联系。

12. 国际数据传输

您的信息可能会被传输到您居住国以外的国家并在其中进行处理。我们的服务提供商（Supabase、Cloudflare、PostHog、RevenueCat，以及当您请求人工智能翻译时的 Google）在全球运营。这些司法管辖区的数据保护法可能与您所在司法管辖区的数据保护法不同。

13. 本隐私政策的变更

我们可能会不时更新本隐私政策。我们将通过更新本政策顶部的“生效日期”以及在可行的情况下提供应用内通知来通知您重大变更。您在任何更改后继续使用服务即表示您接受修订后的隐私政策。我们鼓励您定期查看本隐私政策。

14. 联系我们

如果您对本隐私政策或我们的数据实践有任何问题、疑虑或请求，请通过以下方式联系我们：

电子邮件： 支持@musicmemory.app
